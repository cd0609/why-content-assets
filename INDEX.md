# WHY Carousel Index

Every carousel produced so far. **Read this before writing a new one** — check the hook lines below so a new carousel doesn't quietly repeat an angle already used, and to see what's actually worked. **Append a row after producing new ones** — the rendered slide PNGs can't be read back for their content, only this index (or opening each slide's HTML) can, so a stale or missing entry here means that carousel's content is effectively invisible to future work.

Full output (HTML + rendered PNGs + source photos) for each lives in its own `<slug>/` folder in this directory. All follow `why-carousel-1`'s fixed hook → feeling → brand-statement → fade → solution arc — see that skill for the format itself; this index is just the content record.

## Used hook angles (vary these across new carousels)

Money lost/spent (taxi fare, rent, wage, birthday shoes, borrowed cash), memory loss ("woke up and couldn't remember"), a specific person's reaction (daughter, partner, brother, flatmate, niece), a broken promise to someone by name, the compulsive-repeat behaviour itself (delete/reinstall, "I said I'd have two"), boredom/impulse as the trigger, chasing losses at 3am.
